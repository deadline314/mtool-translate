# [MT-1] 輸出 MTool 可加載的翻譯檔

> 狀態：進行中

## 內文

### 需求
要有一個專門給 MTool 用的翻譯器：讀取 MTool「導出原文」產生的原文檔，翻譯後輸出 MTool「加載翻譯文件」可以直接載入的檔案。

- 輸出格式和原文檔相同（原文對譯文），原文一個字都不能改，否則 MTool 對不上
- 遊戲控制碼（顏色、變數、角色名、圖示、等待、富文字標籤、格式化參數等）翻譯後必須原樣保留，壞掉的控制碼可能讓遊戲出錯
- 純數字、符號這類不需要翻譯的條目直接保留原文
- 翻譯中斷（手動停止、程式關閉、網路或金鑰錯誤）時，已翻好的部分不能遺失，重新開始時從中斷處接著翻

### 來源
使用者，2026-10-19 對話：「我想要做一個專門為了 mtool 的翻譯器，但我不知道該怎麼讓 mtool 可以用我翻譯出來的檔案?」，以及「好，先做 mtool 的版本」。

### 驗收條件
- [x] 選擇 MTool 匯出的原文檔後，輸出檔的條目數量、原文與原文檔完全一致
- [x] 帶控制碼的句子翻譯後控制碼完整保留，例如 `\C[2]アリス\C[0]が仲間になった！` 譯為 `\C[2]愛麗絲\C[0]已加入你的隊伍！`
- [x] 譯文遺失或多出控制碼的條目會重試一次，仍失敗就保留原文，並在記錄列出是哪一條
- [x] 純數字、符號條目不送翻譯、保留原文，並計入「跳過」
- [x] 翻譯中按停止，已完成的條目存在輸出檔；再按開始只翻剩下的條目
- [x] 金鑰錯誤等無法重試的錯誤會立即中止整個工作，中止前已完成的部分有存檔
- [x] 完成後提示到 MTool 翻譯頁「加載翻譯文件」載入輸出檔
- [ ] 用一款實際遊戲在 MTool 匯出原文、翻譯後「加載翻譯文件」，遊戲中的對話與選單顯示譯文，帶控制碼的句子顏色、變數正常（附截圖）

### 測試流程
1. 準備一份 MTool 匯出的原文檔，內含一般台詞、帶控制碼的台詞、純數字條目
2. 開啟翻譯器，選擇原文檔，選任一引擎，按「開始翻譯」
3. 預期：輸出檔與原文檔條目一致，控制碼完整，純數字條目保留原文
4. 換一份較大的原文檔，翻到一半按「停止」，再按「開始翻譯」
5. 預期：第二次只處理剩下的條目，進度從停止的位置接續
6. 在 MTool 翻譯頁用「加載翻譯文件」載入輸出檔，遊戲畫面顯示譯文

# Commit-1

## 內文

原本沒有任何工具能把 MTool 匯出的原文變成 MTool 能載回去的翻譯檔，自己手動翻還要小心不要弄壞控制碼。
現在選擇原文檔、按開始翻譯，就會輸出同格式的翻譯檔：控制碼在送出翻譯前先保護起來、翻完還原；不需要翻的數字和符號自動跳過；每隔幾秒自動存檔，停止或中斷後再開始會從中斷處接續，已翻好的不會重送；金鑰錯誤這類問題會立即中止並保留已完成的部分。
用 8 條的樣本（含 `\C[2]`、`\N[1]`、`<color=red>` 控制碼與純數字）以 MyMemory 實際翻譯，控制碼全部還原、數字條目保留原文；用 400 條的檔案翻到一半停止，輸出檔存了已完成的條目，續翻只處理剩下的部分；模擬金鑰錯誤時工作立即中止，輸出檔仍在。輸出檔還沒有實際載入 MTool 驗證。
