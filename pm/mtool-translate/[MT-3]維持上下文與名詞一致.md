# [MT-3] 維持上下文與名詞一致

> 狀態：進行中

## 內文

### 需求
遊戲文本是一句一句拆開的，逐句翻譯容易失去語境，同一個角色名、地名、物品名在不同句子裡被翻成不同譯名。翻譯時要能理解前後文，並盡量確保專有名詞全篇一致：

- 使用者可以維護術語表（原文對譯名），翻譯時強制使用
- 可以自動從全文找出專有名詞並給出建議譯名，讓使用者檢查後再翻譯
- 每句翻譯時參考前面幾句的原文與譯文
- 可以補充遊戲背景（角色設定、語氣），讓翻譯更貼近原作
- 沒有上下文能力的免費服務，也要能套用術語表

### 來源
使用者，2026-10-19 對話：「翻譯能夠正確處理上下文的關係，盡量確保不會出現名詞不一致的問題」。

### 驗收條件
- [x] 術語表可以新增、編輯、刪除、匯入、匯出，並隨原文檔自動保存與載入
- [x] 「自動擷取術語」會列出原文中的專有名詞與譯名並加入術語表；原文沒有出現的詞不會被加入
- [x] 翻譯時，句子裡出現的術語會帶上指定譯名；譯文沒有使用指定譯名的句子會自動重翻一次，仍未套用則在記錄列出
- [x] 每句翻譯時會附上前文（行數可調，預設 5 行），前文已翻好的會一起附上譯文
- [x] 介面可填寫遊戲背景，翻譯時會一起參考
- [x] 免費服務也會套用術語表，例如術語「アリス → 愛麗絲」在 MyMemory 的譯文中正確出現
- [ ] 用真實 LLM 翻譯一份實際遊戲的原文檔：術語表內的名詞全篇使用同一譯名（抽查至少 3 個主要角色名，出現的每一句都一致）
- [ ] 同一份檔案關閉前文參考與開啟前文參考各翻一次，抽查 10 句對話，開啟後語氣與稱謂較連貫

### 測試流程
1. 選擇一份實際遊戲的原文檔，選 LLM 類引擎
2. 按「自動擷取術語」，預期術語表出現角色名、地名、物品等，檢查並修改譯名
3. 在遊戲背景填入角色設定，按「開始翻譯」
4. 翻譯完成後，在輸出檔搜尋 3 個主要角色名的原文
5. 預期：每一句都使用術語表中的譯名，沒有其他譯法
6. 前文參考行數改為 0 重翻一份，與原本的輸出比較 10 句對話

# Commit-1

## 內文

原本逐句翻譯，同一個名字可能每句譯法都不同，模型也不知道是誰在說話。
現在翻譯前可以先自動擷取專有名詞建立術語表，使用者檢查後再翻譯；翻譯時每批只帶上該批用得到的術語，並附上前幾句的原文與已完成的譯文；譯文沒用指定譯名會自動重翻一次。免費服務沒有上下文能力，術語改成在送出前直接替換成譯名。術語表跟著原文檔保存，下次開啟同一份檔案會自動載入。
用模擬引擎驗證了術語有帶進每批翻譯、前文有附上、模型編造的術語會被濾掉；MyMemory 實際翻譯時「アリス」全部譯為術語表指定的「愛麗絲」。真實 LLM 在完整遊戲上的一致性還沒有驗證。

| MyMemory 套用術語 | 「アリス」2 處皆譯為「愛麗絲」 |
