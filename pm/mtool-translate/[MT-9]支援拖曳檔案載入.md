# [MT-9] 支援拖曳檔案載入

> 狀態：完成

## 內文

### 需求
選原文檔時要按「瀏覽…」一層層找資料夾。希望能直接把 MTool 匯出的 ManualTransFile.json 從檔案總管拖進翻譯器。

- 拖進視窗任何地方都能載入原文檔
- 拖進術語表檔案時合併進目前的術語表
- 拖到程式圖示上，開啟時就直接載入那個檔案
- 拖錯檔案、或翻譯進行中拖入時，要有清楚的提示，不能弄亂進行中的工作

### 來源
使用者，2026-10-19 對話：「然後能不能讓我支援可以拖入檔案的功能?這樣我就可以直接把原文 ManualTransFile.json 檔案拖入」

### 驗收條件
- [x] 從檔案總管把 ManualTransFile.json 拖進視窗任何地方，原文檔、輸出位置、術語表都會載入，下一步提示跟著更新
- [x] 拖入 *.glossary.json 會合併進目前的術語表並存檔
- [x] 同時拖入原文檔與術語表，兩者都會處理；路徑含中文與空白也正常
- [x] 拖入不支援的檔案（例如 .txt）會提示可以拖入哪些檔案，原本的狀態不變
- [x] 翻譯進行中拖入檔案會提示先停止，不會更換檔案
- [x] 把原文檔拖到程式圖示上（或用「開啟檔案」選擇本程式），開啟後直接載入
- [x] 使用說明、Hover 說明與下一步提示都有提到可以拖曳
- [x] 不需要額外安裝套件；無法使用拖放的環境照常運作

### 測試流程
1. 開啟翻譯器，從檔案總管把 ManualTransFile.json 拖進視窗
2. 預期：原文檔欄位顯示該檔案，左下角提示下一步「測試連線」
3. 再把另一份 *.glossary.json 拖進視窗，預期術語表多出裡面的詞
4. 拖一個 .txt 進去，預期出現「不支援的檔案」提示
5. 開始翻譯後再拖檔案進去，預期提示先停止
6. 關閉翻譯器，把 ManualTransFile.json 拖到 exe 圖示上，預期開啟時已載入該檔案

# Commit-1

## 內文

原本只能按「瀏覽…」選檔案。
現在可以把原文檔拖進視窗任何地方，或拖到程式圖示上開啟；拖入 *.glossary.json 會合併進術語表。拖錯檔案、翻譯中拖入都會有提示，不影響進行中的工作。拖放用 Windows 內建機制實作，不需要額外安裝套件。使用說明、Hover 說明、下一步提示都加上了拖曳的說明。
自動化測試會組出真的 Windows 拖放訊息送進視窗，走的路徑跟從檔案總管拖進來完全相同，涵蓋原文檔、術語表、兩者一起、中文加空白路徑、不支援的檔案、翻譯中拖入、拖到圖示開啟，全部通過。也用打包好的 exe 實際測試「拖到圖示上開啟」，原文檔正確載入。
